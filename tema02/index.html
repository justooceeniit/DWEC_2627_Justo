2. Analisis de motores

Muchos navegadores utilizan Chromium porque proporciona una base común para desarrollar un navegador y utiliza el motor de renderizado Blink. Chrome, Edge y Opera están basados en Chromium, aunque cada navegador puede añadir sus propias funciones. Firefox utiliza Gecko, mientras que Safari utiliza WebKit. Por eso no todos los navegadores interpretan exactamente igual una página web, especialmente cuando se utilizan características nuevas o que todavía no tienen el mismo nivel de compatibilidad. Para un desarrollador web esto significa que no basta con probar una página en un único navegador, sino que es recomendable comprobarla en diferentes motores y también en dispositivos móviles. De esta forma se pueden detectar diferencias de compatibilidad y adaptar la página cuando sea necesario.

3. Compatibilidad (Can i use)

Propiedad CSS: subgrid

Una característica que no ha tenido el mismo soporte en todos los navegadores es CSS Subgrid. Esta función permite que un elemento que utiliza CSS Grid pueda utilizar las filas o columnas de la cuadrícula de su elemento padre. Según Can I Use, Safari no soportó CSS Subgrid hasta la versión 16.0. Las versiones de Safari comprendidas entre la 3.1 y la 15.6 aparecen como no compatibles. En cambio, Safari 16.0 y posteriores sí lo soportan. Firefox lo soporta desde la versión 71 y Chrome y Edge desde la versión 117. Esto demuestra que una característica de CSS puede funcionar correctamente en un navegador moderno y no estar disponible en versiones anteriores de otro navegador.
